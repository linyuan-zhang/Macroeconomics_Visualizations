# Macroeconomics Visualizations

# How to Run the Code
## Solow Model — Python
To run the Python code for the Solow model:
Open the notebook in Google Colab.
Upload the Model_Inputs spreadsheet to your own Google Drive.
Use the edited version of Model_Inputs available on GitHub. This version was adapted from the spreadsheet you originally provided; I manually deleted one row so that it could be read more easily by both Python and R.

## Solow Model — R
To run the R code for the Solow model:
Download the .qmd file and the edited Model_Inputs spreadsheet.
Put both files in the same folder.
Open and run the .qmd file using RStudio or VS Code.

## Phillips Curve — Python
The Python code for the Phillips Curve can be run either in Google Colab or locally using an application such as VS Code or Jupyter Notebook.

## Phillips Curve — R
To run the R code for the Phillips Curve, download the relevant file and open it in RStudio or VS Code.

## Viewing the R Output Without Running the Code
To view the R code and visualizations without running R, download the corresponding .html files and open them in a web browser.
